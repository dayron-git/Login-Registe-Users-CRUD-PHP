# Protecto con PHP (login/registe, CRUD) 
Proyecto web dedicado a PHP donde se aplica login/register de usuarios y CRUD, usando XAMP y phpmyadmin

## Instrucciones 
- Instalar XAMPP anda a `https://www.apachefriends.org/es/index.html` y descargá XAMPP para Windows. Instalalo con las opciones por defecto (asegurate de que Apache y MySQL queden marcados para instalar).
- Iniciar Apache y MySQL Abrí el 'Panel de control de XAMPP' y hacé click en 'Start' para Apache y para MySQL. Ambos deberían quedar en verde.
- Descomprimí el .zip del proyecto y copiá la carpeta completa 'EP4_Luna_Store_NRC-1057_Dayron-Lozano' dentro de la carpeta 'htdocs' de XAMPP — normalmente en `C:\xampp\htdocs\`
- Crear la base de datos en el navegador en http://localhost/phpmyadmin, click en 'Nueva' (o 'New') en el panel izquierdo para crear una base de datos, o directamente andá a la pestaña 'SQL' y pegá el contenido del archivo luna_store.sql. Click en 'Continuar' / 'Go'.
- Abrí el navegador en http://localhost/EP4_Luna_Store_NRC-1057_Dayron-Lozano/index.php — ahí debería cargar la página principal del proyecto.
